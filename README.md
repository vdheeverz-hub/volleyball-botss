# Volleyball Legends ELO Bot

## Commands
- /queue mode partner1 partner2 - queue your team
- /leavequeue mode - leave the queue
- /startqueue mode - (admin) randomly pair one match from the queue
- /resolve matchid winner - (admin) resolve a disputed vote
- /closechannel - delete the current match channel
- /leaderboard mode - view rankings
- /stats mode player1 player2 player3 - view a team's rating
